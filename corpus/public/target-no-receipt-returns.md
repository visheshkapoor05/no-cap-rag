# Target — No-Receipt Returns (summary)

- The item and the original payment method (card) must be brought to
  Guest Services; the return must still fall within the standard return
  window even without a receipt.
- Proof of purchase can be looked up automatically if the original
  purchase used a Target Circle Card, Visa, Mastercard, American Express,
  or Discover card.
- Target Plus (marketplace) partner items are an exception with no
  lookup option — proof of purchase is required, full stop.
- Without any provable proof of purchase, the customer receives a
  "merchandise return card" (store-credit-like instrument) instead of a
  refund to a payment method or cash.
