# Returns Exception Matrix

**SOP ID:** SOP-RET-014 · **Version:** 2.0 · **Effective:** June 1, 2026

This is the internal procedure store associates follow when a return falls
outside RET-POL-001's standard rules. It is distinct from RET-POL-001
itself: the policy document states customer-facing rules; this SOP states
what an associate is actually authorized to do at the register when a
situation doesn't cleanly match those rules.

## 1. When to Consult This Matrix

Consult this matrix whenever a return request doesn't cleanly fit
RET-POL-001 — no receipt, a return past the stated window, a final-sale
item a customer insists was mis-tagged, or a discounted item where the
discount percentage isn't obvious from the receipt alone.

## 2. Exception Table

| Situation | Associate authority | Escalation required? |
|---|---|---|
| No receipt, item under $50 | Store credit at lowest 90-day price | No |
| No receipt, item $50 or over | Decline; offer manager review | Yes — shift lead |
| 1–7 days past standard window | Approve at associate discretion | No |
| 8–30 days past standard window | Store credit only, not cash/card refund | No |
| 31+ days past standard window | Decline | Manager may override |
| Disputed final-sale tagging | Do not override at register | Yes — regional manager |
| Discount percentage unclear from receipt | Look up via order ID in POS; do not guess | No |

## 3. New in This Version: Clearance-Tagged Item Exception

Version 2.0 adds one exception not present in version 1.0: items tagged
**clearance** under the Markdown Policy (PROMO-POL-003) that fall within
RET-POL-001's shortened 14-day window (Section 3.2) may still be exchanged
— not refunded — for a different size or color of the identical item, at
the associate's discretion, without escalation, provided the exchange
happens within the same 14-day window. This exception exists because the
14-day window change in Returns Policy v3.0 was driven by refund/margin
concerns specifically, not by a desire to block same-item exchanges, and
store associates were incorrectly declining legitimate size exchanges
under the v1.0 matrix before this clarification was added.

## 4. Manager Override Authority

A shift lead or store manager may override any "No" or "Manager may
override" row above at their discretion, but every override must be logged
with the associate's ID, the customer's reason, and the manager's
justification. Overrides are reviewed monthly; a pattern of overrides
against the same rule is treated as a signal that the underlying policy
may need revision, not that the associate needs correction.
